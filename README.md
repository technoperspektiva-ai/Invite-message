# Invite Message v4 — посилання + конверт + анімація, без R2

Ця версія повертає логіку першого прототипу:

1. На головній сторінці користувач обирає звертання та додає фото.
2. Натискає «Створити запрошення».
3. Отримує окреме посилання виду `/i/xxxxxxxxxxxxxx`.
4. Одержувач відкриває посилання й бачить окрему сторінку з закритим лавандовим конвертом.
5. Після натискання конверт анімовано відкривається, лист виїжджає з нього, а потім відкривається велика листівка.
6. Велику листівку можна закрити кнопкою ×, тапом поза нею або Escape.

## Зберігання

R2, D1 та KV не використовуються. Запрошення зберігаються у Cloudflare Durable Objects, які створюються разом із Worker через migration у `wrangler.toml`. Ніяких bucket/database ID вручну вставляти не потрібно.

Фото перед відправленням стискається у браузері до максимум 720 px по довшій стороні та JPEG quality 0.78.

## Deploy command

У Cloudflare Builds постав:

```bash
npx wrangler deploy
```

Стару команду з `wrangler r2 bucket create ...` потрібно прибрати, бо ця версія R2 взагалі не використовує.
