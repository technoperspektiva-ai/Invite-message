# Invite Message v3 — без R2

Версія повністю без R2, D1 та серверного збереження персональних даних.

## Що змінилось

- Прибрані поля: ім’я, дата, час, місце, дрес-код, заголовок і текст.
- Залишені тільки вибір звертання та завантаження фото.
- Фото не відправляється на сервер і обробляється локально у браузері.
- Передперегляд відкривається у модальному вікні та нормально закривається: кнопкою ×, тапом поза вікном або Escape.
- Кнопка «Надіслати запрошення» генерує PNG локально і відкриває системне Share меню на iPhone/Android. Якщо file-share не підтримується, PNG завантажується.
- У `wrangler.toml` немає жодного R2 binding.

## Deploy

Рекомендована команда Cloudflare Builds:

```bash
npx wrangler deploy
```

Якщо у Cloudflare поки залишена стара команда:

```bash
npx wrangler r2 bucket create love-invite-media || true && npx wrangler deploy
```

сам сайт усе одно задеплоїться, бо R2 більше не використовується, але в логах і далі буде зайва помилка спроби створення R2. Краще змінити команду на `npx wrangler deploy`.
